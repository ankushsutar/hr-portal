# HRMS Roadmap

## Product Vision

> A configurable HR operating system built specifically for Indian companies.
> Organized around the employee lifecycle — from recruitment to exit.

## Core Differentiators

1. **Indian HR workflows first** — OD, WFH, Comp-off, Indian leave, TDS, New Regime, PF, ESIC
2. **ESSL native integration** — First-class biometric attendance adapter
3. **Attendance reprocessing** — Re-run attendance logic after policy/shift changes
4. **Employee Lifecycle Timeline** — Full chronological history per employee
5. **Probation Dashboard** — Automated countdowns and confirmation workflow
6. **Bulk HR Operations** — Unified bulk-ops framework across all modules
7. **Data Quality Center** — Proactive HR data health monitoring
8. **Configuration-driven** — Leave policies, payroll structures, workflow approvals — all configurable without code

---

## Phase 1 — September 2026

**Theme: Employee Lifecycle Foundation**

Deliver a production-ready HR platform covering:
- Employee Master (rich profile)
- User Management + RBAC + Data Scopes
- Onboarding Engine (templates, tasks, documents)
- Bulk Import
- Employee Lifecycle (probation, confirmation, exit)
- Attendance (processing pipeline, OD, WFH, Comp-off, ESSL)
- Leave Engine (configurable policies, LOP)
- Payroll Part 1 (structures, processing, payslips)
- Approval Center
- HR Task Center
- Notification Center
- Data Quality Center
- Reports Foundation

---

## Phase 2 — December 2026

**Theme: Performance, Skills & Advanced Payroll**

- Performance Management (cycles, goals, KPIs, KRAs)
- PIP (Performance Improvement Plans)
- Skills Matrix & Skill Gaps
- Indian Statutory Payroll (PF, ESIC, PT)
- New Tax Regime + TDS computation
- Leave Encashment
- Payroll Reversal
- HR Calendar
- Global Search

## Phase 3 — January 2027

**Theme: Recruitment, Mobility & Advanced Operations**

- Recruitment Engine (requisition → offer → candidate → employee)
- Transfer & Promotion (effective-dated)
- Asset Management (onboarding/exit integration)
- Scheduled Reports
- Advanced Analytics

## What We Are NOT Building

| Feature | Reason |
|---|---|
| Help Desk | Not relevant to core HR operations |
| Multi-currency payroll | India-only |
| SSO / OAuth | Deferred; email+password sufficient |
| Native mobile app | Mobile-responsive web is sufficient |
| CRM integration | Out of scope |
| 360-degree feedback (full) | Manager review is sufficient for Phase 2 |
| Document versioning | Phase 3 at earliest |
